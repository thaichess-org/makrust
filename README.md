# [thaichess.org](https://thaichess.org)

Makrust (mak[ruk in] Rust) is a free and open source [makruk](https://en.wikipedia.org/wiki/Makruk) (Thai chess) game server, built in the spirit of [Lichess](https://lichess.org).

It aims to bring realtime and correspondence play, analysis, and a modern web experience to makruk, an ancient chess variant still played throughout Thailand and Southeast Asia today.

**Status:** very early development. The server is just getting started — see [thaichess.org](https://thaichess.org) for updates.

Makrust is one of several projects that make up the thaichess.org platform:

- [makrukops](https://github.com/thaichess-org/makrukops) — makruk rules and operations in TypeScript.
- [makrukground](https://github.com/thaichess-org/makrukground) — the web makruk board UI.
- [makruk-gif](https://github.com/thaichess-org/makruk-gif) — renders GIFs of makruk positions and games, and streams them frame by frame.
- [pgn-viewer](https://github.com/thaichess-org/pgn-viewer) — a PGN viewer widget for makruk games.

Use [GitHub issues](https://github.com/thaichess-org/makrust/issues) for bug reports and feature requests.

## Installation

```
cargo run
```
